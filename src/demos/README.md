# Demos Directory

Visualization and interactive demonstrations of algorithms.

## Current Demos

### quadtree_demo.cpp
- Interactive 2D QuadTree construction demo
- Step-by-step particle insertion
- Visualizes tree structure and center of mass calculations
- Uses: `algorithms/quadtree2d.cpp`

## Design Philosophy

Files in this directory should:
- Focus on visualization and user interaction
- Use algorithm implementations from `src/algorithms/`
- Depend on raylib for rendering
- Provide educational value through clear visuals
