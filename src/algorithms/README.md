# Algorithms Directory

Pure algorithm implementations with **no rendering dependencies**.

## Current Implementations

### quadtree2d.cpp
- 2D QuadTree spatial partitioning (Barnes-Hut algorithm in 2D)
- Tree construction via recursive subdivision
- Center of mass calculation
- No dependencies on graphics libraries

## Design Philosophy

Files in this directory should:
- Contain only core algorithm logic
- Have no raylib or rendering dependencies
- Be reusable in different contexts
- Focus on computational efficiency
